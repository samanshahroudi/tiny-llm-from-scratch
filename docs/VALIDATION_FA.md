## Training evidence

Both runs used 400 steps with `batch=16`, `seed=7`, `context=64`, `width=64`, `heads=4`, and `layers=2`; only the learning rate changed. Evaluation used the same 12 fixed validation batches.

| Model | Learning rate | Best validation loss |
|---|---:|---:|
| Smoothed bigram | — | 1.9514 on the same batch targets |
| Baseline TinyGPT | 0.002 | 0.3431 |
| Comparison TinyGPT | 0.02 | 0.1796 |

Validation selected the model; the larger rate won in this limited run. After selection, test loss was about 0.1835 and test perplexity about 1.2014. These results come from a synthetic corpus with shared templates and do not demonstrate general language ability. Full reports are in `artifacts/runs/full/report.json`; a readable copy is in `artifacts/demo/controlled_experiment.json`.

A live HTTP observation used a 10-token prompt and generated 40 new tokens in about 134 ms inside the endpoint. This is one machine observation, not a load test or latency guarantee. Free-form quality differs from loss because sampling errors propagate into later context.
